# C++ 后端笔试面试知识库

更新时间：2026-08-26

这套资料只围绕 C++ 后端校招/社招初中级岗位的笔试和面试组织。目标不是把仓库从头读完，而是把每个主题训练到四个层次：能定义、能解释机制、能比较取舍、能结合代码或项目举证。

## 从这里开始

1. 先用 [10 周主线](00-学习路线/10周主线.md) 安排顺序，不要同时从十个仓库开读。
2. 用 [进度看板](00-学习路线/进度看板.md) 做一次闭卷自测，把不会的项目标为待办。
3. 算法每天 1 至 2 题；基础知识每天选 1 个问题做 3 分钟口述。
4. 每周至少做一次 90 分钟笔试模拟和一次 45 分钟技术面试模拟。
5. 用 [复盘与答题模板](00-学习路线/复盘与答题模板.md) 留下可检索的答案，不以“看过”作为完成标准。

在 PowerShell 中搜索本知识库：

```powershell
cd E:\BaiduNetdiskDownload\Anything\Pre
.\search.ps1 'TIME_WAIT'
.\search.ps1 'BufferPoolManager' -Code
```

也可以直接用 VS Code 打开 [C++后端面试.code-workspace](C++后端面试.code-workspace)，其中已排除 Git 元数据和大型媒体目录的全文搜索干扰。

## 学习优先级

| 优先级 | 模块 | 面试完成标准 |

| P0 | 数据结构与算法 | 高频题型可在 25 至 35 分钟内写出可编译 C++17 代码 |

| P0 | MySQL、Redis | 能解释索引、事务、锁、MVCC、日志、缓存一致性和常见优化 |
| P0 | 项目 | 至少一个项目能讲清架构、调用链、难点、证据、边界和改进 |
| P1 | C++ 并发与内存模型 | 能解释 happens-before、原子序、条件变量及常见竞态 |
| P1 | 高性能网络编程 | 能解释非阻塞 I/O、epoll、Reactor、线程模型、背压和连接管理 |
| P1 | 系统设计 | 能完成估算、API、数据模型、核心链路、扩展和故障处理 |

| P2 | 数据库内核、分布式原理 | 用于项目加深和中高阶追问，不应挤占 P0 时间 |

## 默认训练节奏

工作日每天约 2 小时：

```text
45 分钟算法 -> 45 分钟专题 -> 20 分钟闭卷口述 -> 10 分钟复盘
```

周末每天约 4 小时：

```text
90 分钟模拟笔试 -> 90 分钟项目/实验 -> 45 分钟模拟面试 -> 15 分钟修订答案
```

算法贯穿全部 10 周，基础知识按路线推进。若只剩 4 周，先完成每周 P0 验收项；若有 12 周，把第 7 至 9 周各拆成两周。

## 资料使用原则

- 仓库是参考材料，不是学习进度。只读与当前问题直接相关的章节。
- 每道理论题至少补一个代码片段、命令输出、时序图或项目实例。
- 所有“掌握”都要通过闭卷复述、手写代码或可复现实验验证。
- 项目表述区分“框架已有”“自己实现”“自己调试验证”，不扩大个人贡献。
- Star 数仅用于筛选，不代表内容正确；最终以标准文档、源码和实验为准。

## 最终验收

- 45 分钟内完成两道中等算法题，代码可编译并覆盖边界。
- 90 分钟内完成一套 C++/OS/网络/数据库混合笔试，错题能归因。
- 从 [高频问题](08-题库/高频问题.md) 随机抽 20 题，至少 16 题能在 3 分钟内结构化回答。
- 能在白板上画出一次请求从 DNS、TCP、HTTP、服务线程、缓存、数据库到响应的全链路。
- 至少一个项目能进行 30 分钟连续答辩，并能现场定位相关源码与测试证据。
