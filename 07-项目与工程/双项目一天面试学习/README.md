# RMDB 与智能交通一天面试学习

根据当前简历及本地项目源码整理的完整学习资料，核查于 2026-09-15 至 2026-09-16。按知识点学习两个项目的机制、面试主问、递进追问、参考答案和实现边界。

- 52 张知识卡：RMDB 28 张、ITMS-BD 24 张，每张附 3 个带答案追问。
- 32 张 P0 核心卡、20 张 P1 进阶卡；另有 10 组综合模拟及 20 个追问。
- 一天路线包含 9 小时净学习，也提供 4 小时和 90 分钟压缩方案。
