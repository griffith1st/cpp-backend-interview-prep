# 系统设计

## 面试流程

1. **澄清需求**：核心功能、用户量、读写比、延迟、可用性、一致性、数据保留。
2. **容量估算**：QPS、峰值系数、对象大小、日增量、带宽、缓存和副本。
3. **接口与模型**：API、幂等键、核心表/索引、数据生命周期。
4. **高层架构**：入口、服务、缓存、数据库、队列、对象存储、搜索。
5. **深挖瓶颈**：热点、分片、复制、一致性、故障、降级。
6. **可观测性与演进**：指标、日志、追踪、告警、压测、灰度、容量计划。

不要一上来堆组件。每个组件都应对应一个已确认的约束。

## 核心主题

- 负载均衡、无状态服务、服务发现、健康检查。
- 缓存策略、命中率、淘汰、热点、穿透/击穿/雪崩。
- 数据库复制、分片键、再分片、全局唯一 ID、二级索引。
- 消息队列：解耦、削峰、至少一次、重复、顺序、积压和死信。
- 幂等：请求 ID、状态机、唯一约束、去重表、可重放操作。
- 限流：令牌桶/漏桶/滑动窗口；熔断、超时、重试、退避和抖动。
- 一致性、可用性、分区、读己之写、最终一致和补偿。
- 多级容灾：进程、机器、机房、地域；RPO/RTO。
- 安全基本面：认证、授权、输入校验、密钥、审计和最小权限。

## 六道必练题

| 题目 | 重点 |
| --- | --- |
| 短链接 | ID 生成、重定向读路径、缓存、过期、热点 |
| 即时聊天 | 长连接、在线状态、消息顺序、离线消息、多端同步 |
| 秒杀/库存 | 限流、预扣、热点、幂等、超卖、异步化 |
| 订单/支付 | 状态机、事务边界、幂等回调、对账、补偿 |
| 日志采集 | agent、缓冲、批量、背压、分区、检索、保留策略 |
| 文件存储 | 分片上传、元数据、对象存储、校验、CDN、权限 |

每题至少补三个故障：缓存失效、下游超时、消息重复或积压、主库故障、热点分片。

## 容量估算示例骨架

```text
DAU = ...
每用户每日请求 = ...
平均 QPS = DAU * 请求数 / 86400
峰值 QPS = 平均 QPS * 峰值系数
日新增存储 = 写请求数 * 单条大小 * 副本数
峰值带宽 = 峰值响应数 * 平均响应大小
```

数字可以是假设，但量纲、数量级和后续架构必须一致。
