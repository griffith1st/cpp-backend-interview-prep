## C++ 笔试检查表

提交前逐项检查：

- 空数组、单元素、全部相同、负数、重复元素、极值。
- `int` 是否溢出；计数、乘积、距离是否需要 `long long`。
- 下标是否越界；`size_t - 1` 是否在空容器下回绕。
- 递归深度是否可能爆栈；图是否需要 visited。
- 比较器是否满足严格弱序；priority_queue 的大小顶方向是否写反。
- 输入是否有多组；字符串是否含空格；输出格式是否有多余字符。
- 时间复杂度是否满足约束；哈希最坏情况是否需要说明。
- 修改容器时是否导致迭代器/引用失效。

## 训练循环

```text
首刷：限定 35 分钟，不看答案
复盘：写出模式、不变量和失败样例
二刷：2 天后，限定 25 分钟
三刷：7 天后，只看题意闭卷写
变式：改变数据范围、返回形式或在线数据条件
```

完成标准不是“AC 过一次”，而是随机抽题时能说明为什么正确，并能根据约束选择合适实现。
