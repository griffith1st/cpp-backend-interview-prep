## 1 复杂度与正确性

先确认输入规模、值域、有序性、重复值、边权和输出要求，再选算法。复杂度是随规模变化的增长，不是程序实测毫秒数。O(n) 与 O(n log n) 在小输入上的实际快慢可能受常数、缓存和分配影响，但规模增长仍受渐近成本约束。

| 概念 | 解释 | 容易误判 |
| --- | --- | --- |
| 最坏复杂度 | 最不利合法输入的上界 | 平均哈希 O(1) 说成严格最坏 O(1) |
| 均摊复杂度 | 一串操作总成本分摊 | vector 扩容单次线性与均摊常数冲突 |
| 额外空间 | 算法除输入外使用的存储 | 忽略递归栈、临时排序数组与输出 |
| 输出下界 | 输出本身的大小约束运行时间 | 枚举所有子集却声称总时间 O(n) |

正确性不能只靠几个测试：循环不变量说明每轮前后维持的事实，归纳说明子问题到大问题，交换论证支撑贪心，反证解释为何丢弃候选不失去最优解。测试用于寻找反例和实现错误，证明用于覆盖抽象输入范围。

常见量级仅作训练参考：n=10^5 时 O(n²) 通常危险，O(n log n) 常可行；n=20 的子集枚举可能可做。但时间限制、常数和机器不同，不能用固定表替代测量。

## 2 数组、链表与哈希

数组连续存储、下标定位常数、遍历局部性好；插入中间需搬移。链表节点非连续，已知节点的链接操作可常数，但查找节点仍线性。双向链表用更多指针换取反向定位与已知节点删除。

链表题先画指针，不要同时覆盖所有变量：反转时保存 next，再改 cur->next，最后推进 prev/cur。快慢指针相遇用于检测环；寻找环入口需证明起点到入口的距离关系，不能只背“相遇后重置一个”。删除节点还要确认谁拥有并释放该节点。

哈希表保存已处理前缀的信息，典型是两数和、频次、去重和索引。两数和先查补数再插入当前值，可避免同一元素被用两次；重复值仍需要位置判断。整数补数计算需宽类型或范围约束。

前缀和把区间求和转换为差值：prefix[i] 表示前 i 个元素和，区间 [l,r) 为 prefix[r]-prefix[l]。负数不影响这个恒等式，却会破坏某些滑动窗口的单调性。差分数组处理大量区间增量，最后累加还原；它不是任意动态查询的通用解。

滑动窗口的关键不是双指针外形，而是“不合法时移动左端能恢复、且右端推进不漏候选”的性质。求和至少为 K 在正数数组可收缩；加入负数后可能需要前缀和+单调队列。

## 3 栈、队列与单调结构

栈适合后进先出依赖：括号匹配、表达式求值、递归模拟。队列适合先进先出层次扩展：BFS、事件排队。用 vector.erase(begin()) 模拟队列会反复线性搬移，可用 deque 或头下标。

单调栈保存尚未找到答案的候选索引。找下一个更大元素时，读到新值 x，连续弹出较小值并确定答案，再把 x 入栈。每个元素最多进出一次，因此总 O(n)，即使代码有内层 while 也不是必然 O(n²)。相等时弹不弹取决于“严格更大”或“大于等于”。

单调队列解决滑动窗口最大值：队头移除过期索引，队尾移除被新值支配的候选，队头就是当前最大值。必须存索引或能判断过期的信息；只存值会在重复值时难以区分寿命。

面试反例：窗口大小为 0、k>n、数组全相等、严格递减。先澄清题设是否允许这些输入，然后给约定结果，而不是让代码越界后再解释。

## 4 二分、排序与区间

二分搜索建立在单调判定上，不限有序数组。找第一个满足 P 的位置时，维护候选半开区间 [l,r)，不满足则 l=mid+1，满足则 r=mid。终点可能是 n，返回后访问前先检查。

答案二分例：把连续任务分给 k 人、最小化最大负载。在非负工作量前提下，给定容量 C 是否可在 k 段内完成是单调判定；先定义上下界，再用线性贪心检查。若允许任意非连续分组，问题结构已经改变。

| 排序 | 时间 | 空间与性质 |
| --- | --- | --- |
| 插入排序 | 最坏 O(n²) | 可稳定，近乎有序和小数组可能合适 |
| 归并排序 | O(n log n) | 数组常需 O(n) 辅助空间，可稳定 |
| 快速排序 | 平均 O(n log n)，朴素最坏 O(n²) | 分区原地但有递归栈，通常不稳定 |
| 堆排序 | O(n log n) | 原地，不稳定，局部性代价需考虑 |
| 计数/基数 | 依值域、位数而定 | 不是基于比较的通用 O(n log n) 下界场景 |

`std::sort` 的复杂度契约不等同于“每种实现都恰好采用某个固定排序源码”。稳定性、额外空间和比较器必须按 API 契约选择。区间合并先排序，再维护当前已合并区间右端；端点相接是否合并取决于开闭区间语义。

## 5 树与堆

树题常见模板是“返回当前子树的信息”：高度、是否平衡、最大路径、是否满足搜索树约束。验证 BST 不能只比较父子，应传递合法值域或检查中序全局有序；重复键如何放置先约定。

DFS 前序适合根到叶路径，中序关联 BST 有序性，后序适合先求子树再合并。递归深度等于树高，链状树可能栈溢出；迭代显式栈不降低渐近空间上界，但可避免依赖较小调用栈。

堆只保证父子局部顺序，不是全局有序数组。保留最大的 K 个值通常维护大小 K 的小根堆，新值大于堆顶才替换；O(n log K)，K=0 单独处理。要输出有序结果还需额外排序/弹出成本。

平衡搜索树通过结构调整约束高度，哈希通过分桶换平均精确查找性能；数据库 B+ 树强调高扇出、页 I/O 和叶层范围扫描，不能直接用二叉树节点复杂度回答磁盘索引。

## 6 图、最短路与并查集

邻接矩阵空间 O(V²)，适合某些稠密图；邻接表 O(V+E)，适合稀疏遍历。无向边通常需存两个方向。多重边、自环、节点编号不连续都影响建图。

| 问题 | 方法 | 成立条件与不变量 |
| --- | --- | --- |
| 可达性 | DFS/BFS | visited 防止重复扩展 |
| 最少边数路径 | BFS | 无权或等权，按层首次到达最短 |
| 非负权最短路 | Dijkstra | 当前最小距离可确定；跳过过期堆项 |
| 含负边 | Bellman-Ford 等 | 处理可达负环，最坏 O(VE) |
| 有向依赖排序 | 拓扑排序 | 零入度没有未满足前驱；输出不足说明有环 |
| 动态合并连通块 | 并查集 | 根代表集合；合并与查找不直接解决删边 |
| 最小生成树 | Kruskal/Prim | 无向带权连通图；与源点最短路不同 |

Dijkstra 的非负条件是正确性前提。边 S->A=2、S->B=5、B->A=-10 会让提前固定 A 错误。堆允许同节点多项时用 dist 比较跳过旧项；对一般多重图可按 O((V+E) log E) 分析，简单图中常写 O((V+E) log V)。

并查集按秩/大小合并配合路径压缩，操作序列有接近常数的摊还复杂度，严格说是反 Ackermann 量级。只压缩不合并策略、支持撤销的版本有不同分析，不应机械照搬。

## 7 回溯与动态规划

回溯枚举状态树：选择、递归、撤销。剪枝需证明分支已不可能满足约束或优于当前答案；组合、排列、允许重复、元素重复是不同问题。排序加同层去重常用于重复组合，但不要误删不同深度的合法选择。

DP 由重叠子问题和最优子结构驱动。先写状态含义，再写转移、初始化、遍历顺序、答案位置。dp 的数字没有明确语义时，代码再熟也难以改题。

| 类别 | 状态示例 | 常见错误 |
| --- | --- | --- |
| 一维序列 | 前 i 项的最优值/计数 | 把空前缀初始化为不可达 |
| 0/1 背包 | 前若干物品、容量 j | 一维正序更新使同物品重复使用 |
| 完全背包 | 可重复物品下容量 j | 遍历顺序改变组合与排列计数 |
| 区间 DP | [l,r] 区间最优 | 区间长度顺序与边界错位 |
| 树形 DP | 子树在选择/不选择时的值 | 父子依赖没进入状态 |
| 状态压缩 | mask 描述已选集合 | 低估 2^n 状态和转移成本 |

最长递增子序列可 O(n²) DP，也可维护各长度的最小结尾做 O(n log n)。结尾数组本身不一定是一条真实子序列；需要恢复路径时保存前驱，不要直接输出它。严格递增与非递减对应不同二分边界。

## 8 贪心与字符串

贪心每一步局部选择，要证明局部选择可延伸为全局最优。区间调度按最早结束选取，交换论证说明替换最优解第一项不会缩小后续空间；任意硬币面额的最少硬币却未必能贪心。

字符串先声明模型：字节、Unicode 码点与用户感知字符不同。ASCII 固定数组计数简单，UTF-8 的一个字符可能多个字节。C++ char 的符号性实现相关，用字符值作为数组索引需先转 unsigned char 并确认值域。

KMP 的前缀函数记录“当前前缀的最长真前后缀”，失配时复用已知相等信息；构建与匹配总线性，但拼接串时需要保证分隔符不在输入字符集中。Trie 按字符走边，适合前缀查询，节点内存与字符集大小是代价。

## 9 五道完整推演

### 9.1 和为 K 的子数组

输入 [1,-1,1]，K=1，答案 3。设当前前缀和 s，需要此前出现 s-K 的次数；初始化 count[0]=1，表示空前缀。依次得到 s=1 增 1、s=0 增 0、s=1 增 2，总 3。必须先统计答案再登记当前 s，避免 K=0 时把空区间计入。期望 O(n) 时间、O(n) 空间，计数可能达 n(n+1)/2，需要足够宽整数。

### 9.2 二分左边界

[1,2,2,4] 找第一个 >=2。l=0,r=4，mid=2 满足使 r=2；mid=1 满足使 r=1；mid=0 不满足使 l=1，结束返回 1。找 5 则返回 4，不访问 a[4]。不变量是 [0,l) 均不满足、[r,n) 均满足。

### 9.3 最少硬币

面额 [1,3,4]、目标 6。dp[0]=0，dp[s]=min(dp[s-c]+1)，仅从可达状态转移。dp[3]=1、dp[4]=1、dp[6]=2，对应 3+3。贪心 4+1+1 得 3，构成反例。目标非负、面额严格正且可无限使用；时间 O(amount×面额数)，空间 O(amount)。

### 9.4 课程依赖

边 0->1、0->2、1->3、2->3。初始入度 [0,1,1,2]，出队 0 后 1/2 入队，两者都处理后 3 才入队。合法顺序不唯一；返回任何拓扑序和求字典序最小是不同要求，后者可使用小根堆。新增 3->1 后 1/3 循环，输出节点数不足。

### 9.5 LRU 缓存

容量 2，put(1,A)、put(2,B)、get(1)、put(3,C)。访问顺序变化后 2 最旧，应淘汰 2。哈希 key->list 迭代器，双链表头最新尾最旧；命中移到头，淘汰同步删哈希。已有 key 更新不增容量。平均 O(1)，容量 0、引用寿命和并发另做契约。

## 10 工程数据结构与项目映射

数据库连接、缓冲页和任务都可能用队列，但淘汰与调度策略不同。buffer pool 中 pinned 页不可被替换，标准 LRU 不包含这个约束；要结合候选集合与 pin 计数。缓存加并发锁后要保持 map/list 同步，不能只分别线程安全。

Join 选型连接算法与 I/O：朴素嵌套循环的比较成本可达 O(NM)，哈希连接的平均探测受哈希分布与内存限制，排序归并连接受排序成本和输入有序性影响。数据库具体代价还包括页、过滤、回表和中间结果，不等于纯内存算法的一个 O 符号。

族谱关系可映射为图遍历，但数据可能有缺失或错误边，不能无条件假设是一棵树。深度限制、visited、批量访问数据库和稳定分页都影响真实服务；10 万级模拟数据不等于 10 万真实用户。

## 11 C++ 编码与测试

默认函数接受 const 引用避免大容器复制；需要修改输入时提前说明。递归 lambda、引用捕获和返回局部引用有寿命风险。priority_queue 比较器方向、unordered_map 的 operator[] 会插入、vector 下标不检查范围，都是面试实现错误高发点。

给每题构造三组测试：正常输入；空/单元素/全等/极值等边界；最能击穿假设的反例。图加入环、不可达和重复边；DP 加入不可达、0 目标；二分加入全部满足与全部不满足。

对可穷举的小输入，可用朴素正确实现与优化实现做差分测试。随机测试要保存种子、最小失败输入和期望值；与同样有 bug 的“暴力解”比较并不证明正确。算法题外的完整工程还需错误处理、异常与资源寿命。

## 12 训练计划与参考

两周按天覆盖：数组哈希、链表、窗口前缀、单调结构、二分、排序区间、树、堆、BFS拓扑、最短路并查集、回溯、DP、贪心字符串、混合模拟。每天一道新题加一道错题变式，保留第一次独立用时和提示级别。

现场 35 分钟可分为 5 分钟约束与样例、8 分钟暴力到优化、15 分钟实现、7 分钟测试与复杂度。目标是可编译、可解释、能改条件，而不是刷题数量。
