## 来源与边界

正文按原题重新组织，是面试解释与推演，不是大段复制第三方文章。各专题末尾列出继续阅读入口；社区整理用于建立问题清单，关键机制优先对照规范、官方手册与固定版本源码。

- C++：cppreference、C++ 工作草案、Core Guidelines 及 Clang/GDB 文档。在线工作草案随新标准变化，C++17 面试需核对对应版本规则。
- Linux 与网络：Linux man-pages，TCP RFC 9293、重传计时 RFC 6298、HTTP RFC 9110/9111、TLS 1.3 RFC 8446、QUIC RFC 9000。
- 数据库：MySQL InnoDB 8.4 文档、PostgreSQL MVCC 文档、Redis 事务、持久化与分布式锁文档。记录适用引擎，避免把某一数据库实现直接套到另一数据库或教学内核。
- Muduo：对照主仓库固定提交 `f1fc77e0c13b80e5086ff457362c8a86d1b609d4` 的 EventLoop、Channel 和 EPollPoller；该路径未默认设置 EPOLLET。高水位回调不等于应用已经实施背压。
- 设计与项目：容量数字为显式假设；建议实验不是实际执行结果；参考项目具备某功能不代表学习者实现过该功能。

审校补充了 Redis 执行错误不回滚、ET 提前让出处理的就绪队列、幂等 PROCESSING 状态失联接管等边界。复核的计算包括页表 4 MiB、有效访存 115 ns、LRU 六次缺页，以及网络 BDP、TCP 序号、短链容量和积压消化时间。
