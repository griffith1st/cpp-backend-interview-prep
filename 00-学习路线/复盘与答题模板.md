# 复盘与答题模板

参考答案见 [105 题答案索引](../08-题库/答案索引.md)。使用 AI 时可配合 [专项提示词](../09-AI学习/提示词库.md)，先独立作答，再看反馈；实际测试与推演结果分开记录。

## 理论题：3 分钟结构

```text
1. 一句话定义：它解决什么问题。
2. 核心机制：关键状态、数据结构、时序或不变量。
3. 取舍边界：优缺点、适用条件、替代方案。
4. 工程例子：代码、项目、命令或故障案例。
5. 追问准备：性能、并发、异常、扩展性。
```

不要只背名词。例如回答 epoll 时，应包含 fd 注册、就绪队列、LT/ET、非阻塞读取到 EAGAIN、惊群/线程模型，而不是只说“效率高”。

## 算法题：现场顺序

```text
1. 复述输入输出和约束，确认空值、重复、范围、是否有序。
2. 给出暴力解和复杂度，建立正确性基线。
3. 识别模式并解释为什么能优化。
4. 先说不变量/状态定义，再写代码。
5. 用正常、边界、失败三类样例手推。
6. 报告时间/空间复杂度和可能的工程改进。
```
