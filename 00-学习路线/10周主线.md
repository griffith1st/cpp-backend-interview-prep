# 10 周 C++ 后端面试主线

默认投入每周 14 至 18 小时。算法每天不断线，专题按周推进。每周的“验收”必须闭卷完成。

逐题复习使用 [105 题答案索引](../08-题库/答案索引.md)。需要 AI 带练时，从 [使用指南](../09-AI学习/README.md)和 [P0 启动提示词](../09-AI学习/提示词库.md#p0-直接启动)开始；提示后答对与首次独立答对分开记录，不由 AI 自动勾选本路线验收项。

## 第 0 周：基线与目标岗位

- 收集 20 条目标岗位 JD，统计 C++、Linux、网络、数据库、算法、项目关键词。
- 做一套 90 分钟算法笔试，记录正确率、完成时间、编译错误和边界遗漏。
- 从高频题库随机抽 30 题口述，按“会 / 模糊 / 不会”分类。
- 选定一个主项目：已有 RMDB 优先；网络方向可选 Muduo 阅读线；数据库方向可选 BusTub 阅读线。

验收：产出岗位关键词表、初始分数和项目边界说明。

## 第 1 周：C++ 基础与 STL

- 初始化、类型转换、const、引用、指针、数组、函数重载、模板基础。
- vector/deque/list/map/unordered_map/set 的结构、复杂度与迭代器失效。
- string、algorithm、lambda、自定义比较器与哈希。
- 算法：数组、哈希、双指针、链表。

验收：闭卷写一个简化 vector；解释 vector 扩容、unordered_map 冲突和 map 红黑树取舍。

## 第 2 周：对象模型、RAII 与现代 C++

- 构造/析构、拷贝/移动、Rule of 0/3/5、继承、多态、虚函数。
- 左值/右值、完美转发、智能指针、异常安全、对象生命周期。
- C++11/14/17 高频特性：auto、lambda、constexpr、move、optional、variant、结构化绑定。
- 算法：栈、队列、二叉树、堆。

验收：实现线程安全资源包装器；解释 shared_ptr 控制块、循环引用和 move 后对象状态。

## 第 3 周：操作系统与 Linux

- 进程、线程、调度、上下文切换、IPC、同步原语和死锁。
- 虚拟内存、页表、TLB、缺页、写时复制、内存映射。
- 文件系统、文件描述符、阻塞/非阻塞、零拷贝、select/poll/epoll。
- Linux 命令：ps/top/pidstat/strace/lsof/ss/gdb/perf。
- 算法：二分、排序、区间。

验收：画出虚拟地址到物理页的转换；用 strace 解释一个程序的文件和网络系统调用。

## 第 4 周：计算机网络

- TCP 状态机、三次握手、四次挥手、可靠传输、流控、拥塞控制和重传。
- TIME_WAIT、CLOSE_WAIT、半连接/全连接队列、粘包、心跳和背压。
- DNS、HTTP/1.1、HTTP/2、HTTP/3、HTTPS/TLS、代理与负载均衡。
- Socket API、非阻塞连接、epoll LT/ET、Reactor 线程模型。
- 算法：回溯、DFS/BFS。

验收：从浏览器输入 URL 讲到服务端响应；能定位 TIME_WAIT/CLOSE_WAIT 异常的责任端与命令。

## 第 5 周：MySQL 与 Redis

- B+ 树、聚簇/二级索引、联合索引、覆盖索引、回表、最左前缀、EXPLAIN。
- ACID、隔离级别、MVCC、Read View、锁、死锁、redo/undo/binlog。
- SQL 优化、分页、批量写、连接、统计信息和慢查询。
- Redis 数据结构、持久化、过期/淘汰、缓存穿透/击穿/雪崩、缓存一致性。
- 算法：动态规划入门、背包。

验收：给定 SQL 和索引判断访问路径；画出一次事务更新涉及的锁与日志。

## 第 6 周：C++ 并发与性能

- thread、mutex、unique_lock、condition_variable、future、线程池。
- data race、happens-before、atomic、CAS、memory_order、ABA、伪共享。
- 内存分配、缓存局部性、对象池、性能测量与基准测试。
- Sanitizer、perf、火焰图、core dump 的基本工作流。
- 算法：进阶 DP、图、并查集、最短路。

验收：实现有界阻塞队列和固定线程池；解释条件变量为何必须配合谓词循环。

## 第 7 周：项目源码与调用链

- RMDB 线：SQL -> Parser -> Planner -> Executor -> Storage -> Disk。
- Muduo 线：EventLoop -> Poller -> Channel -> TcpConnection -> Buffer。
- BusTub 线：BufferPool -> PageGuard -> B+Tree -> Executor -> Transaction。
- 每个主讲点保存调用链、状态变化、失败路径、测试证据和实现边界。
- 算法：综合题，每次完整计时。

验收：30 分钟项目答辩；随机打开关键函数，3 分钟说明调用者、状态和异常路径。

## 第 8 周：系统设计

- 需求澄清、容量估算、API、数据模型、核心链路和瓶颈定位。
- 缓存、分片、复制、消息队列、幂等、限流、熔断、降级、重试。
- 一致性与可用性、主从延迟、热点、雪崩、故障恢复和可观测性。
- 练习：短链、聊天、秒杀、订单、日志收集、文件存储。

验收：45 分钟完成一道系统设计，给出数字估算、故障场景和取舍。

## 第 9 周：专项查漏与面经

- 按目标公司题库抽题，不按仓库顺序通读。
- 聚类错题：知识缺口、表述不清、代码错误、时间失控、项目证据不足。
- 回看 C++ 高频 UB、STL 失效、TCP 状态、MySQL 索引/锁和项目追问。
- 准备自我介绍、项目介绍、离职/求职动机和反问。

验收：两场完整模拟面试；同一问题的 30 秒、3 分钟、10 分钟版本均可表达。

## 第 10 周：全真模拟与收口

- 两套 120 分钟笔试，严格限制查资料。
- 三场 60 分钟技术面试：算法、基础、项目、系统设计混合。
- 只修订高频错题和项目证据，不再无边界扩展资料。
- 整理面试当天清单：环境、输入模板、常见边界、项目图和反问。

验收：达到 README 的最终验收标准；未通过项进入单独补强清单。
